2. Benefits of R projects

R projects let you organize your projects (in this case assignments) easily with all related files in one place. .Rproj file contains instructions for R Studio on how to open the project between sessions. In also provides source control integration in this case it is Git.

3. Git and GitHub

Git is a version control technology that let’s an individual or team effectively contribute to a projector task. Developers make changes, stage them and create commits that are snapshots of code at that particular point in time. This makes it easy to track history, collaborate, create branches and forks, merge and sometimes revert the changes (say toa w working version).

GitHub is a cloud based platform that let’s you host your Git projects. Essentially, a GitHub repo URL becomes the remote/origin for the source code. Individual/team can clone the repo, make changes locally, create branches, and push the changes to back to GitHub. GitHub also provides collaboration and development feature such as pull requests, issue tracking, code reviews, and CI/CD tools

Git and GitHub together form the foundation for CI/CD aspect of software/data engineering projects.

4. Differences between tibble and data.frame

  1. A tibble is a stricter version of data.frame that makes programming with former more consistent and predictable
  2. tibble prints data better than data.frame
  3. tibble doesn’t coerce down a vector when you subset to only one using [

getIQR <- function(x, ...) {
 q <- quantile(x, probs = c(0.25, 0.75),...)
 x[x >= q[1] & x <= q[2]]
}
